# ASCII Art generator
## What is ASCII ART?
ASCII stands for American Standard Code for Information Interchange sounds complex, right? But it's simple: each character from A to ⋚ are stored in this standardised format. in this, there are very diverse set of charecters which when plaed in a text file makes example:

## What does this app do?
It takes normal text and converts it into ASCII art through a Python program and an easy-to-use UI.
![https://cdn.hackclub.com/01a14638-7d00-7c8e-b125-4e4a26b8fcf9/Screenshot%202026-10-17%20010623.png]
## How to use the app.
1. Install Python.
2. Install the Flask library.
3. Copy, paste or run the code in base.py
4. Input your text and get your art
